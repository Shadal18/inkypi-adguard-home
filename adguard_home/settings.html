🛡️ AdGuard Home

Display DNS protection, traffic trends, client activity, and filtering health.

Connect InkyPi to your AdGuard Home server, select the sections to render, protect sensitive DNS information, and tune display colors for six-color Waveshare panels.

💡

Connection guidance

Use the direct dashboard address, such as http://192.168.1.2:3000, or the root URL of your reverse proxy. The InkyPi host must be able to reach this address.

🔌

AdGuard connection

Enter the server endpoint and credentials InkyPi should use.

Use the direct interface URL or a reverse-proxy root address.

🧭

Layout and thresholds

Control display density and when blocked-query warnings appear.

Use the warning color when the blocked-query percentage reaches this level.

Use the alert color when the blocked-query percentage reaches this level.

📊

Display sections

Choose which information blocks appear on the dashboard image.
🕶️

Privacy and color profile

Hide sensitive information and tune colors for your e-paper display.

Enable masking if the e-paper display is visible to visitors, streamed through a camera, or placed in a shared room.
